# 📖 Blog Académico - Narrativa Digital vs. Tradicional

## 📖 Descripción del Proyecto
Este repositorio contiene el código fuente de un blog académico desarrollado como proyecto para la materia de *Lectura y Escritura en el Contexto Digital* de UNIMINUTO (Corporación Universitaria Minuto de Dios). 

🔗 **[Visita el proyecto en vivo haciendo clic aquí](https://sebastianrodriguez02.github.io/Blog-Lectura-y-escritura-en-el-contexto-digital/)**

## 📚 Historia y Contexto
El objetivo de este trabajo fue trasladar un análisis investigativo sobre las diferencias entre las formas de contar historias (tradicional vs. digital) a un entorno web interactivo. 

Aunque el contenido textual e ilustrativo fue producto de un trabajo colaborativo y apoyado por herramientas de Inteligencia Artificial, **mi rol exclusivo en este proyecto fue el Desarrollo Web**. Mi objetivo fue tomar esa información y construir desde cero toda la arquitectura, diseño y maquetación de la página para darle un formato de revista digital profesional.

## 🔨 Estructura y Funcionalidades

El proyecto destaca por su construcción técnica enfocada en la legibilidad y el diseño editorial:
*   **Diseño Editorial Web:** Estructuración visual de un artículo académico que incluye barra lateral (sidebar) para conceptos clave, fuentes consultadas y autores.
*   **Maquetación Semántica:** Uso estructurado de etiquetas HTML5 para organizar el contenido (títulos, subtítulos, citas destacadas) asegurando una lectura fluida.
*   **Estilizado con CSS Puro:** Implementación de una paleta de colores sobria, tipografías legibles y distribución de elementos sin depender de frameworks externos como Bootstrap.
*   **Diseño Estático:** Despliegue de información directa y rápida, ideal para la lectura prolongada en pantallas.

## 🛠️ Tecnologías utilizadas

*   HTML5
*   CSS3
